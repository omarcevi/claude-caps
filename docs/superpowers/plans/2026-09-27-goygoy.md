# goygoy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `goygoy`, a Claude Code plugin that answers every submitted prompt with the Turkish meme "Başımla beraber abi! 🫡" — as audio in sound mode, or said by Claude itself in text mode.

**Architecture:** One `UserPromptSubmit` hook runs `scripts/goygoy.sh`, which looks the event up in a data registry (`memes.json`) and either backgrounds an audio player (clip via `afplay`, else macOS TTS voice Yelda) or prints hook JSON whose `additionalContext` tells Claude to open its reply with the phrase. The mode lives in a one-word file written by `scripts/mode.sh`, which the two slash commands `/goygoy:sus` and `/goygoy:konus` call. Shared mode resolution lives in `scripts/lib.sh`.

**Tech Stack:** bash (macOS `/bin/bash` 3.2), `jq` 1.7 (`/usr/bin/jq`), `afplay`, `say`; Claude Code plugin manifests (JSON) and command files (Markdown). Tests: plain bash + `perl` for millisecond timing.

**Spec:** `docs/superpowers/specs/2026-09-27-claude-caps-design.md`

## Global Constraints

- Platform: macOS only. All scripts must run under macOS `/bin/bash` **3.2** — no `mapfile`/`readarray`, no associative arrays, no `${var,,}`/`${var^^}`, no `$EPOCHREALTIME`.
- Runtime dependencies: only `jq`, `afplay`, `say` (all ship with macOS 26). Tests may additionally use `perl`.
- Plugin name `goygoy`; marketplace name `claude-caps`; install id `goygoy@claude-caps`.
- Commands: `/goygoy:sus` → text mode, `/goygoy:konus` → sound mode. ASCII-only command and file names.
- Mode file: `${XDG_CONFIG_HOME:-$HOME/.config}/goygoy/mode` containing `sound` or `text`. `$GOYGOY_MODE` (`sound`|`text`) overrides it. Default: `sound`.
- Phrase: `Başımla beraber abi! 🫡` — clip filename `basimla-beraber-abi.mp3` in `sounds/` — TTS voice `Yelda`.
- Text-mode `additionalContext`, exactly: `Start your reply with exactly "<phrase>" on its own line, then continue normally.`
- Confirmation lines, exactly: `goygoy: konuşuyor 🔊 (sound)` and `goygoy: sustu 🤫 (text — Claude söyleyecek)`.
- The hook must never block or break Claude Code: every failure path in `goygoy.sh` exits 0 with empty stdout; players run in the background with stdout **and** stderr redirected to `/dev/null`; hook `timeout` is `5`.

## Review Focus

1. **Yelda voice not installed** (a friend's Mac, or voices removed) — expected: falls back to the default `say` voice instead of going silent. Pinned in Task 2.
2. **Phrases with quotes, backslashes, Turkish letters, emoji** — expected: text-mode JSON stays valid and the phrase arrives byte-for-byte. Pinned in Task 2.
3. **Plugin installed under a path containing spaces** — expected: everything still works. Pinned in Task 1: the whole suite runs from a directory named `my plugin`.
4. **Hand-edited mode file** (` text\r\n`, `banana`) — expected: surrounding whitespace/CRLF tolerated, unknown words fall back to `sound`. Pinned in Task 1.
5. **`GOYGOY_MODE` exported while running `/goygoy:sus`** — expected: the confirmation reports the *effective* mode and names the override instead of falsely claiming it muted. Pinned in Task 1.

Not unit-testable, checked live in Task 3: the player surviving the hook process's exit (Claude Code must not kill the backgrounded sound).

```bash
# Shared helpers for goygoy scripts. Source this file; don't execute it.
# Must stay compatible with macOS /bin/bash 3.2.

# Path of the saved mode file.
goygoy_mode_file() {
  printf '%s/goygoy/mode\n' "${XDG_CONFIG_HOME:-$HOME/.config}"
}

# Saved mode ("sound" or "text"); prints nothing if unset or unrecognized.
goygoy_saved_mode() {
  local file saved
  file="$(goygoy_mode_file)"
  [ -r "$file" ] || return 0
  saved="$(tr -d '[:space:]' < "$file")"
  case "$saved" in
    sound|text) printf '%s\n' "$saved" ;;
  esac
}

# Effective mode: $GOYGOY_MODE if valid, else the saved mode, else "sound".
goygoy_mode() {
  case "${GOYGOY_MODE:-}" in
    sound|text) printf '%s\n' "$GOYGOY_MODE"; return 0 ;;
  esac
  local saved
  saved="$(goygoy_saved_mode)"
  printf '%s\n' "${saved:-sound}"
}
```

# Usage: mode.sh [sound|text|status]
# Saves the goygoy mode and prints the effective one. Run by /goygoy:sus and /goygoy:konus.

source "$(dirname "$0")/lib.sh"

case "${1:-status}" in
  sound|text)
    file="$(goygoy_mode_file)"
    if ! { mkdir -p "$(dirname "$file")" && printf '%s\n' "$1" > "$file"; } 2>/dev/null; then
      echo "goygoy: could not save the mode to $file" >&2
      exit 1
    fi
    ;;
  status) ;;
  *)
    echo "usage: mode.sh [sound|text|status]" >&2
    exit 2
    ;;
esac

case "$(goygoy_mode)" in
  text) echo "goygoy: sustu 🤫 (text — Claude söyleyecek)" ;;
  *)    echo "goygoy: konuşuyor 🔊 (sound)" ;;
esac

case "${GOYGOY_MODE:-}" in
  sound|text) echo "  (GOYGOY_MODE=$GOYGOY_MODE is set in your environment and overrides the saved setting)" ;;
esac

```bash
#!/usr/bin/env bash
# Hook entry point: goygoy.sh <HookEventName>   (hook JSON arrives on stdin)
# sound mode: plays the meme clip, or speaks the phrase, in the background; prints nothing.
# text mode:  prints hook JSON telling Claude to open its reply with the phrase.
# A meme must never break Claude Code, so every failure path exits 0 silently.

exec 2>/dev/null
cat >/dev/null # drain the hook payload; unused in v1

event="${1:-}"
root="$(cd "$(dirname "$0")/.." && pwd)" || exit 0
source "$root/scripts/lib.sh" || exit 0
memes="$root/memes.json"

command -v jq >/dev/null || exit 0
count="$(jq --arg e "$event" '.[$e] | if type == "array" then length else 0 end' "$memes")" || exit 0
case "$count" in
  ''|0|*[!0-9]*) exit 0 ;;
esac

meme="$(jq -c --arg e "$event" --argjson i "$((RANDOM % count))" '.[$e][$i]' "$memes")" || exit 0
phrase="$(jq -r '.phrase // empty' <<<"$meme")"
sound="$(jq -r '.sound // empty' <<<"$meme")"
[ -n "$phrase" ] || exit 0

if [ "$(goygoy_mode)" = text ]; then
  jq -cn --arg e "$event" --arg p "$phrase" '{
    hookSpecificOutput: {
      hookEventName: $e,
      additionalContext: ("Start your reply with exactly \"" + $p + "\" on its own line, then continue normally.")
    }
  }'
  exit 0
fi

# Players must not inherit our stdout: Claude Code waits for that pipe to close.
clip="$root/sounds/$sound"
if [ -n "$sound" ] && [ -f "$clip" ]; then
  afplay "$clip" >/dev/null 2>&1 &
else
  { say -v Yelda "$phrase" || say "$phrase"; } >/dev/null 2>&1 &
fi
exit 0
```

````markdown
# goygoy 🫡

Turkish meme reactions for Claude Code. Give Claude a task and it answers
**"Başımla beraber abi!"** — out loud, or in its own reply.

## Install

```
/plugin marketplace add ~/Documents/Programming/claude_caps
/plugin install goygoy@claude-caps
```

Then drop the clip at `sounds/basimla-beraber-abi.mp3`. Until it's there,
the phrase is spoken with the built-in Turkish voice (Yelda).

## Use

| Command | What it does |
|---|---|
| `/goygoy:sus` | Mute: Claude starts its reply with the phrase instead |
| `/goygoy:konus` | Sound on (default) |

`GOYGOY_MODE=text` or `GOYGOY_MODE=sound` in the environment overrides the saved mode for that session.

## Add a meme

Add an entry to `memes.json` under a hook event and put the clip in `sounds/`:

```json
{
  "UserPromptSubmit": [
    { "phrase": "Başımla beraber abi! 🫡", "sound": "basimla-beraber-abi.mp3" },
    { "phrase": "Another one for the same moment", "sound": "another.mp3" }
  ]
}
```

Several memes on one event are picked at random. `sound` is optional (TTS is used without it).
A new event (e.g. `Stop`) also needs an entry in `hooks/hooks.json`. Run `/reload-plugins` after changes.

## Test

```
./tests/test_goygoy.sh
```
````
